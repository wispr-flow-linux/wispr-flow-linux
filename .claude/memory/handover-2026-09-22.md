## Conventions to keep

- Branch names `fix/<issue>-desc` or `feature/<issue>-desc`; squash-merge
  with `(#N)` in the subject; `Co-Authored-By: Claude <claude@anthropic.com>`
  trailer on commits. Issues and PRs are short and plain (CLAUDE.md, "Issues,
  PRs, and commits"): a few sentences, evidence in the commit body, one
  `Co-Authored-By: Claude <model> <noreply@anthropic.com>` line at the end.
  Comments carry no trailer. The old percentage block and "Written by" line
  are retired; #83, #84 and today's comments were rewritten to the new shape.
- Bash: tabs, 80 cols, `[[ ]]`, no `set -e` (except the existing
  `scripts/patches/` files, which use `set -euo pipefail` and 2-space indent
  as house style there; `scripts/build-linux.sh` is 2-space too).
- Shellcheck, actionlint and codespell before every push. `grep` is shadowed
  by a ugrep wrapper in this shell; use `/usr/bin/grep` when a byte-count or
  `-o` result matters. `$TMPDIR` is unset; use the session scratchpad path.
- Any desktop smoke launch must use an isolated `HOME`/`XDG_*` so the
  maintainer's live profile is never migrated, and must say so first.
- `build.log` in the repo root is untracked scratch; leave it alone.
- `nix` is not installed on this host, so the helper v0.1.2 hash for #40
  cannot be computed here.
