## Conventions to keep

- Branch names `fix/<issue>-desc` or `feature/<issue>-desc`; squash-merge
  with `(#N)` in the subject and a written body (what, why, what was
  verified, `Fixes #N`, co-author lines); `Co-Authored-By: Claude
  <claude@anthropic.com>` trailer on commits. Issues and PRs are short and
  plain (CLAUDE.md, "Issues, PRs, and commits"); PR bodies end with the
  `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>` line. Comments
  carry no trailer.
- To land a fork PR: `git fetch origin pull/N/head:pr-N`, work in a
  `git worktree` under the session scratchpad, `git merge origin/main`,
  edit, run `bats tests/*.bats`, the CI shellcheck line
  (`git grep -l '^#\( *shellcheck \|!\(/bin/\|/usr/bin/env \)\(sh\|bash\|dash\|ksh\)\)' -- '*.sh' | xargs shellcheck -x --severity=warning`),
  `codespell`, `actionlint`, run each new patch twice on the pristine
  bundle, then push to the contributor's branch under maintainer edits and
  `gh pr merge N --squash --subject ... --body-file -`. A cherry-pick keeps
  the author's commit; put your own additions in a second commit.
- Resolve conflicts with line-anchored markers (`^<<<<<<< `, `^=======$`);
  same-block appends in `build-linux.sh`, `MARKERS=(` and
  `MARKER_SAMPLES` are keep-both. `CHANGELOG.md` Unreleased conflicts when
  two PRs add at the top of the same list; keep main's bullets first.
- A stacked PR says so in its first line. `ci.yml` only triggers on PRs
  against `main`, so a PR based on another branch gets its gates with
  `gh workflow run ci.yml --ref <branch>`; after the base lands,
  `git rebase --onto origin/main <old-base-sha> <branch>`, force-push, and
  `gh pr edit N --base main`.
- Bash: tabs, 80 cols, `[[ ]]`, no `set -e` (except the existing
  `scripts/patches/` files, which use `set -euo pipefail` and 2-space indent
  as house style there; `scripts/build-linux.sh` is 2-space too).
- `codespell` scans `.claude/memory/` too (`check-hidden = true`), and it
  flags two-letter minified identifiers. In fixtures, an inline
  `codespell:ignore <word>` directive works with a lowercase word (codespell
  2.4.2 compares the ignore list case-sensitively against the lowercased
  hit). In prose, describe the identifier instead of naming it.
- `grep` is shadowed by a ugrep wrapper in this shell; use `/usr/bin/grep`
  when a byte-count or `-o` result matters. `$TMPDIR` is unset; use the
  session scratchpad path.
- Pristine extracted asars live only in the session scratchpad;
  `npx @electron/asar extract extract/nupkg/lib/net45/resources/app.asar <dir>`
  recreates 1.6.897 in seconds. `extract/` is version-checked on reuse;
  `extract-1.5.789/` (untracked, not gitignored) holds 1.5.789 for
  comparisons and trips `codespell` locally on its SVGs (CI never sees it).
- `xorg-x11-server-Xvfb` is installed, so the AppImage artifact test's
  headless launch runs locally. Any desktop smoke launch must use an
  isolated `HOME`/`XDG_*` so the maintainer's live profile is never
  migrated, and must say so first.
- `build.log` in the repo root is untracked scratch; leave it alone.
- A per-job CI log needs
  `gh api --allow-escape-sequences repos/<owner>/<repo>/actions/jobs/<id>/logs`
  while the run is in progress; `gh run view --log` returns nothing until
  the whole run completes.
